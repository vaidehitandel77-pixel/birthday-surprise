# Birthday Surprise 💗

A tiny, mobile-friendly birthday gift made with plain HTML, CSS, and JavaScript. No build step, account, or backend is needed.

## Personalize it

1. Open `script.js`.
2. Change `friendName` to her name (or leave it empty for “Birthday Girl”).
3. Edit the five entries in the clearly marked `letters` array.
4. To include a picture, copy it to `assets/photo.jpg`, then set `PHOTO_PATH` to `"assets/photo.jpg"`.
5. To include music, copy an MP3 to `assets/birthday.mp3`. Music is only played after the visitor taps the music button.
6. To change colors, edit the variables at the top of `style.css`.

## Run locally

Open `index.html` in a browser. For the same behavior as a hosted site, serve this folder with any simple static-file server; no package install is required.

## Publish with GitHub Pages

1. Sign in to GitHub and choose **New repository**. Name it `birthday-surprise`; make it public, then create it.
2. On the repository page, choose **Add file → Upload files**. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder if you added photo or music. Commit the upload.
3. Go to **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Wait for the Pages panel to show the published link. It will look like `https://YOUR-USERNAME.github.io/birthday-surprise/`.
5. Open the link on your phone to check it, then send it in WhatsApp, Instagram, or a message.

GitHub's menus can shift slightly over time; the Pages settings panel shows the current publishing status and URL.
